# MyMacCalendar 전체 기능 점검표

- 점검일: 2026-08-04
- 점검 브랜치: `codex/mymaccalendar-stability-fixes`
- 범위: 현재 README, SwiftPM 패키지, 전체 Sources/Tests, 앱 번들, 개인 배포 패키지, 격리된 실제 앱 UI
- 원칙: 실제 사용자의 Application Support 저장소와 알림 데이터를 사용하지 않음

## 판정 기준

- **UI 통과**: 격리 앱을 실제로 띄워 Computer Use로 조작하고 결과까지 확인함
- **동작 테스트 통과**: 값을 실행해 결과를 비교하는 결정론적 XCTest가 통과함
- **구조 검사 통과**: 소스 문자열 또는 배선 구조 검사만 통과함. 실제 UI 동작의 증거로 보지 않음
- **부분 확인**: 일부 계층만 확인했거나 현재 환경에서 최종 결과를 관찰하지 못함
- **미구현**: 화면 또는 사용자 흐름이 존재하지 않음

전체 112개 테스트 중 68개는 동작/저장소/fake-client 테스트이고, 44개는 SwiftUI/AppKit 소스 구조 검사다.

## 17. 최종 판정

**부분 통과**다. 일정/반복/빠른 추가/휴일/설정/영구 저장/저장 실패 rollback/알림 경쟁 상태의 핵심 로직과 주요 실제 UI 흐름은 통과했다. 그러나 다음 항목 때문에 `모든 기능 완전 통과`로 판정하지 않는다.

1. 위젯 드래그를 이번 Computer Use에서 실제로 성공시키지 못했다.
2. 반복 occurrence 상세가 선택 occurrence가 아닌 anchor 날짜를 보여준다.
3. 실제 macOS 알림 권한과 전달은 최종 서명 앱에서 검증하지 못했다.
4. 백업/복원, 연도 변경 자동 휴일 fetch, 휴일 편집은 미구현이다.
5. 공개 배포 서명과 notarization은 Developer ID 부재로 차단됐다.
6. 레거시 fixture 마이그레이션은 통과하지만 SDK 경고가 남는다.

다음 개발 작업에서는 위 미완료/부분 확인 항목을 우선순위 후보로 삼고, 이미 통과한 기능에는 회귀 테스트를 유지한다.
