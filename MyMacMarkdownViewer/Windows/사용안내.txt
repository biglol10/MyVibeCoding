MyMarkdownViewer — Windows 11 / Intel·AMD 64비트

1. ZIP 파일 전체를 원하는 폴더에 압축 해제합니다.
2. MyMarkdownViewer.exe를 두 번 클릭합니다.
   EXE만 따로 옮기면 실행할 수 없습니다. 함께 들어 있는 파일과 폴더를 유지하세요.
   Node.js, Python 또는 별도 WebView 설치는 필요하지 않습니다.

Ctrl+O 문서 열기 / Ctrl+Shift+O 폴더 열기 / Ctrl+S 저장
Ctrl+P 빠른 파일 열기 / Ctrl+F 문서 검색 / Ctrl+H 찾아 바꾸기 / Ctrl+Shift+F 폴더 검색
Ctrl+/ 라이브 편집·원문 전환 / Ctrl+Shift+L 사이드바 숨기기 / Ctrl+Z 실행 취소

파일 탭의 폴더 이름 옆 ••• 메뉴 또는 파일을 오른쪽 클릭하여
문서·폴더 생성, 이름 변경, 이동, 탐색기에서 보기, 휴지통 보내기를 사용합니다.
문서는 한 번 클릭하여 열고, 하단 왼쪽 아이콘에서 사이드바와 설정을 엽니다.
폴더 전체 바꾸기는 변경 전·후를 검토하고 파일별로 선택한 뒤 적용합니다.
다른 프로그램에서 파일을 변경하면 저장을 중단하고 복구본을 유지합니다.
파일 → 임시본 복구 메뉴에서 저장하지 못한 문서를 열 수 있습니다.

문서는 원래 위치에 보관합니다. 설정·복구·백업은 Windows 사용자 AppData의
앱 전용 폴더에 저장합니다. 실행 폴더 자체가 모든 데이터를 담는 USB형 포터블은 아닙니다.
UTF-8 Markdown(.md, .markdown)을 지원하며 기존 BOM과 줄바꿈을 보존합니다.

개인용 서명 없는 배포본입니다. 조직의 실행 정책에 따라 실행이 제한될 수 있습니다.
현재 검증 환경은 macOS에서 실행한 동일 Electron 앱 및 자동 테스트입니다.
실제 Windows PC 실행·Windows 한글 IME 검증은 아직 하지 않았습니다.

표의 “표 편집”에서 셀·행·열·정렬을 바꿉니다. Enter·Tab 또는 포커스 이동으로 셀 입력을 반영합니다.
파일 메뉴: HTML/PDF 내보내기와 인쇄(Ctrl+Alt+P).
보기 메뉴: 집중 모드(F8), 타자기 모드(F9).
참조 링크·각주·[toc]·문서 정보 표시를 지원합니다.
이미지 파일·DOCX·EPUB 내보내기와 사용자 CSS 테마는 포함되지 않습니다.
여러 파일 바꾸기를 한 번의 실행 취소로 되돌리는 기능은 없습니다.
실제 클라우드 동기화 충돌과 모든 파일 시스템의 저수준 동시 쓰기를 보장하지 않습니다.

이어 읽기: 앱을 다시 열면 마지막 문서·읽던 위치·폴더를 복원합니다.

현재 문서 찾기: 파일 탭 상단의 과녁 모양 버튼을 누르면 상위 폴더를 펼치고 현재 파일을 선택합니다. 본문에서 읽던 위치는 유지됩니다.
