# 조용한 문서 공간

긴 글을 편하게 읽고, 필요한 부분만 자연스럽게 고쳐 보세요.

MyMarkdownViewer는 **표준 Markdown 파일**을 원래 위치에서 엽니다. 문서를 클릭하면 현재 블록의 원문이 나타나고, 다른 블록은 읽기 좋은 모습으로 유지됩니다.

## 읽기에 맞춘 기본값

| 설정 | 기본값 |
| --- | --- |
| 테마 | 다크 모드 |
| 글자 크기 | 17px |
| 줄 간격 | 1.7 |
| 최대 읽기 폭 | 800px |

앱 설정에서 다크·Night(청회색)·라이트·시스템 테마, 글꼴과 읽기 폭을 바꿀 수 있습니다.

## 자연스럽게 수정하기

- **⌘O**로 문서를 엽니다.
- **⌘⇧O**로 폴더를 열고 **⌘P**로 파일을 찾습니다.
- **⌘F**로 현재 문서를 검색합니다.
- **⌘⇧M**으로 전체 원문과 라이브 편집을 전환합니다.
- **⌘S**로 저장하고 **⌘Z**로 실행을 취소합니다.

> 입력을 멈추면 1초 후 자동 저장합니다. 다른 프로그램의 변경과 내 편집이 겹치면 자동 저장을 멈추고 확인할 수 있게 합니다.

## 표·수식·다이어그램

수식 $E = mc^2$도 문장 안에서 읽을 수 있습니다.

$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$

```mermaid
graph LR
  A[문서 열기] --> B[읽기와 편집]
  B --> C[안전하게 저장]
```

수식과 다이어그램을 클릭하면 해당 블록의 원문을 수정할 수 있습니다.
