# 읽는 흐름 그대로

긴 문서를 읽다가 필요한 문장만 고쳐 보세요. 커서를 옮겨도 제목과 문단의 간격을 유지하도록 다듬었습니다.

## 문장 안에서 자연스럽게

**굵은 글씨**, *기울임*, ~~취소선~~과 `짧은 코드`를 문장 안에서 읽을 수 있습니다. 해당 표현에 커서를 놓으면 그 부분의 Markdown 문법이 나타납니다.

수식 $E=mc^2$도 문장 안에 함께 표시합니다. [Markdown 소개](https://www.markdownguide.org/) 같은 링크는 ⌘키를 누른 채 클릭하면 브라우저에서 열립니다.

## 목록은 한 항목씩

1. 첫 번째 항목은 읽기 모양을 유지합니다.
2. 이 항목을 클릭하고 문장을 수정해 보세요.
3. 주변 항목의 들여쓰기와 줄 간격은 유지됩니다.

- 큰 주제 아래에 내용을 정리합니다.
  - **중요한 내용**을 중첩 목록에 적습니다.
  - 다음 항목은 그대로 읽을 수 있습니다.
- 다른 주제로 이어 갑니다.

- [x] 본문과 제목의 간격 확인
- [ ] 목록 한 항목을 클릭해 보기
- [ ] 원문 전환 후 실행 취소 확인

> 좋은 편집 화면은 읽는 흐름을 방해하지 않습니다.
> 인용문도 문서 안에서 바로 수정할 수 있습니다.
