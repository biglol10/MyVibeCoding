# App icon

2026-09-06. Original artwork generated with the built-in image generation tool.

Final artwork: `AppIcon-Artwork.png`. The AppKit build script applies the macOS
rounded-square mask, transparent margins and all ten ICNS representations.
The generated artwork is deliberately full bleed: a painted transparency grid
must never become part of the final icon.

## Design prompt

Create one production macOS app icon for MyMarkdownViewer, a premium,
distraction-free Markdown reading and writing app. Deep midnight navy satin
background. Center an ivory document sheet, gently curved, with a folded
upper-right corner, soft ambient shadows and crisp layered depth. A bold
sculpted dark-navy hash (#) and two short blue-gray text strokes identify
Markdown. Restrained ice-blue folded corner. Balanced margins, illumination
from upper-left, excellent recognition at 32 pixels. Original design; no
existing app logos, extra text, decorative objects or presentation mockups.

Final preparation: preserve the document artwork and extend the navy texture
to every edge and corner. Supply a full-bleed square texture, without a frame,
transparent margins or checkerboard; the asset pipeline applies the mask.
