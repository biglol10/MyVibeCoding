# 아이콘 교체 및 현재 Mac 실기기 검증

환경: Apple Silicon Mac, macOS 26.6.2. 배포 ZIP을 새 검증 폴더에 풀어 실행했다.
사용자 작업 문서 대신 앱 전용 QA 폴더에 생성한 문서를 사용했다.

## 아이콘

입체적인 종이와 Markdown의 `#`를 중심으로 아이콘을 교체했다.
내장 이미지 생성 도구로 원화를 만들고, 앱 빌드 과정에서 투명 여백과
16–1024px 표현을 생성한다. 32px·128px·256px 크기를 직접 확인했다.

원화와 생성 프롬프트: [아이콘 제작 기록](../Resources/Icon/Design.md).
완성 아이콘: [미리보기](../Resources/Icon/AppIcon-Preview.png) · [ICNS](../Sources/App/Resources/AppIcon.icns).

## 발견한 문제와 수정

- `⌘W`가 동작하지 않아 표준 닫기 메뉴와 단축키를 추가했다.
- 문서 전환 잠금 중에도 서식 명령·체크박스로 원문을 바꿀 수 있었다.
  실패하는 WebKit 회귀 테스트로 재현한 뒤 입력 경로에 잠금·조합 확인을 적용했다.
- 새 문서를 ‘변경 버리기’로 닫은 뒤 복구본이 다시 생기는 경우를 발견했다.
  진행 중인 복구 쓰기가 끝난 뒤 복구본을 제거하고 기존 편집 세션도 끝내도록 바꿨다.
  최종 설치본에서 변경 버리기 후 프로세스 종료 및 해당 복구본 부재를 확인했다.
- 검색·바꾸기 화면의 문구를 한글로 맞췄다.

## 현재 Mac에서 확인한 항목

- 네이티브 새 문서·저장 창, 닫기·종료 취소 후 내용 유지와 계속 편집.
- 한글과 복합 이모지 붙여넣기, 검색·전체 바꾸기·실행 취소·원문 전환.
- 실제 WKWebView의 다크·라이트 테마, 표·수식·Mermaid 표시.
- 변경 없는 문서의 바이트 보존, BOM·CRLF, 자동 저장, 저장 후 실행 취소.
- 실제 파일 조정자를 지연시키는 동안 편집: 진행 중인 저장에는 이전 내용만
  기록되고 최신 입력은 미저장 상태로 남는다. 다음 저장에 최신 입력이 포함된다.
- 외부 변경과 내 변경 충돌 시 덮어쓰기 중단.
- 외부 삭제 후 열린 내용 유지와 파일 자동 재생성 방지.
- 쓰기 권한을 제거한 QA 폴더에서 저장 실패: 원본·미저장 편집본·복구본 유지.
  권한 복원 후 저장 성공.
- 미지원 인코딩 파일을 열려 할 때 현재 문서 유지.
- 설치본 프로세스 강제 종료 후 새 프로세스에서 복구.

최종 기계 판정과 측정값은 `verification-results.json`에 기록한다.
긴 문서 입력 측정은 프로그램으로 편집 명령을 전달한 처리 시간이며
물리 키보드의 전체 입력 지연이나 실제 IME 검증을 대신하지 않는다.

## 다음 기능 진행 조건

자동 테스트와 현재 Mac의 검증을 통과하더라도 ‘모든 환경에서 완벽함’을
의미하지 않는다. 실제 두벌식 물리 키보드 입력은 사용자 확인을 요청한 상태다.
자동화 도구의 개별 키 입력은 기본 macOS 텍스트 필드에서도 자모가 분리되어
그 결과로 실제 조합 성공 여부를 판정할 수 없었다.

Intel·macOS 14 실제 하드웨어, 실제 동기화 공급자 계정, Apple 공증도 별도다.
따라서 사용자 조건에 따라 다음 범위인 파일 관리·폴더 전체 검색은 아직 추가하지 않았다.
