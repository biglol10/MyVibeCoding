# 파일 관리·폴더 검색 검증

2026-09-09. 개발 소스와 별도 식별자의 검증용 앱 기준이다. 기존 배포 ZIP 및 `/Applications` 설치본은 교체하지 않았다.

후속 업데이트: 아래는 기능 개발 당시의 기록이다. 이후 사용성 보완과 Universal Release 빌드·설치를 완료했다. 현재 설치 상태는 [설치 검증](Release-Install-Verification.md)을 따른다.

## 구현 범위

- 사이드바 `+`와 항목의 오른쪽 클릭 메뉴: 문서·폴더 생성, 이름 변경, 작업 폴더 안으로 이동, 휴지통 보내기 확인 창.
- 열린 문서 이동 전 저장, 이동 후 저장 경로·파일 감시·편집 세션 갱신, 실행 취소 이력 유지.
- 이동한 문서의 상대 링크 보정. 폴더 내부에서 함께 이동하는 상대 연결은 그대로 유지하고 외부 대상을 가리키는 상대 경로를 보정한다. 다른 문서의 들어오는 링크는 수정하지 않는다. 폴더 내 숨김 `.md`도 보정하지만 심볼릭 링크·패키지 내부는 제외한다.
- 폴더 전체 일반 문자열 검색, 대소문자 구분, 결과의 행·열·본문 표시와 정확한 위치 선택.
- 변경 전·후와 일치 부분 미리보기, 파일별 선택 적용, 원본·경로 사전 확인, 파일별 저장 결과. 오류·취소·1,000개 초과 결과는 완전한 검색으로 취급하지 않는다.

## 직접 실행한 검증

환경: Apple Silicon / macOS 26.6.2. TypeScript 검사와 편집기 빌드, Swift 테스트, Xcode arm64 Debug 빌드를 직접 실행했다.

| 계층 | 결과 | 주요 확인 |
| --- | --- | --- |
| Swift | 26개 통과 | 기존 10개 + 파일 관리 8개 + 폴더 검색 8개 |
| Markdown | 6개 통과 | 기존 4개 + 폴더 내부·외부 링크 구분, 이름 변경 시 자기 참조 |
| WebKit | 22개 통과 | 기존 20개 + 이동 후 실행 취소·이전 세션 무시, 검색 범위 선택 |
| 네이티브 앱 | 신규 11개 항목 통과 | 열린 문서 이동·저장·실행 취소, 폴더 링크 보정, 검색·선택·바꾸기·본문 갱신·새 검색 결과·부분 실패 |

별도 앱 식별자 `com.personal.MyMarkdownViewer.WorkspaceQA`와 전용 QA 폴더를 사용했다. 실제 사용자 문서는 검증에 사용하지 않았다. 기존 저장·충돌·복구·권한 실패·테마·긴 문서 검증도 같은 앱에서 다시 통과했다.

부분 실패 검증은 두 번째 파일의 쓰기 조정을 지연시키고 외부에서 내용을 바꿔 재현했다. 첫 파일만 저장되고 두 번째 파일의 외부 내용은 유지되며, 파일별 성공·충돌 결과가 구분되었다.

## 실제 화면 확인

- 파일 탭의 `+` → 이름 입력 → 새 문서 생성·열기를 직접 조작했다.
- 검색 결과의 문서 이름·행·일치 내용과 본문 선택을 확인했다.
- 변경 미리보기에서 원문과 변경 후 내용을 확인하고, 한 파일을 제외한 뒤 다른 파일에 적용했다. 결과 화면에서 `저장됨`과 `선택 제외`가 구분되었다.
- 적용 결과에 미리보기 행이 남는 문제를 발견해 목록의 화면 단계 식별자를 분리하고 최종 앱에서 재확인했다.
- 휴지통 보내기 확인 창을 열고 취소했으며, 문서가 유지되었다. **실제 시스템 휴지통 이동·Finder 복원은 이번 검증에서 수행하지 않았다.**

## 제한과 후속 확인

- 실제 두벌식 물리 키보드 조합은 미확인이다. [검증표](Korean-IME-Checklist.md)를 사용한다.
- 이번 네이티브 검증은 arm64 Debug 앱이다. Intel·macOS 14 실행, 새 Universal Release ZIP, 공증·다른 Mac 배포는 검증하지 않았다.
- 실제 iCloud·OneDrive·Dropbox 계정에서의 동시 수정은 미확인이다.
- 전체 바꾸기와 폴더 이동 후 링크 보정은 여러 파일에 걸친 단일 트랜잭션이 아니다. 일부 성공을 명시하며, 백업·복구본을 사용한다. 전체 바꾸기의 일괄 실행 취소는 제공하지 않는다.
- 상대 경로 보정 중 오류가 나면 이동 자체는 완료될 수 있다. 보정 실패 파일과 복구본을 안내한다.
- 표 셀 편집, 복잡한 문서 전용 표시, 집중·타자기 모드, 내보내기, Windows 앱은 후속 범위다.
