# Windows 포터블 배포 검증 — 2026-09-09

대상은 사용자 승인한 Windows 11 Intel·AMD x64입니다. ZIP 전체를 압축 해제하고 `MyMarkdownViewer.exe`를 실행합니다. Electron 런타임을 함께 넣었습니다. macOS 설치 앱과 기존 macOS ZIP은 이번 Windows 패키징으로 교체하지 않았습니다.

## 직접 실행한 검증

환경: macOS 26.6.2, Apple Silicon arm64, Electron 44.3.0(Chromium), Node 22.23.1. 사용자 실제 문서 대신 임시 폴더의 한글 파일명·공백·이모지 문서를 사용했습니다.

## 화면 직접 검토와 보완

실제 창을 촬영하여 기본 크기와 내용 영역 800×560에서 확인했습니다. 긴 경로를 줄바꿈하고 변경 전·후를 구분했습니다. 이동 목적지는 폴더 목록에서 선택합니다. 입력 오류 시 대화상자를 닫지 않아 재입력할 수 있습니다. 현재 문서가 든 폴더를 펼치며, 미리보기는 적용 후 결과로 교체합니다. 최소 크기에서도 설정의 취소·적용 버튼과 하단 상태줄이 보이도록 수정했습니다.

화면 기록은 `Windows/test-results/`의 `electron-narrow.png`, `replace-review.png`, `replace-outcome.png`, `settings-narrow.png`입니다. OS 글꼴과 제목 표시줄은 실행 환경인 macOS의 것으로, Windows 화면 촬영을 의미하지 않습니다.

## 아직 확인하지 않은 항목

- 실제 Windows PC에서 ZIP 실행·권한·휴지통·Windows 파일 잠금
- 물리 키보드의 Windows 두벌식 입력 및 조합 중 삭제·선택 교체·실행 취소
- 실제 클라우드 동기화 폴더, 조직 보안 정책, Windows ARM64
- Windows 코드 서명: 개인 배포본에 서명하지 않았습니다.

ZIP 구조와 PE 아키텍처 검사 결과·해시·최종 패키지 내용 검사는 `windows-verification-results.json`에 기록합니다. Windows 실행 성공으로 확대 해석하지 않습니다.

최종 Windows ZIP 안의 `resources/app.asar`를 macOS Electron 런타임에서 직접 로드하여 앱 연결 17개 항목을 다시 통과했습니다. 배포 코드·화면·편집기 파일 8개의 원본 일치, ZIP 전체 무결성, AMD64 PE 형식과 라이선스·런타임 포함을 확인했습니다. 이는 Windows EXE 자체를 Windows에서 실행한 검증과 구분합니다.
