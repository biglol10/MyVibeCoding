# UI 사용성 보완 검증 — 2026-09-09

후속 업데이트: 아래는 UI 보완 당시의 기록이다. 이후 Universal Release 앱·ZIP 생성과 Applications 앱 교체를 완료했다. 현재 설치 상태는 [설치 검증](Release-Install-Verification.md)을 따른다.

## 변경 범위

- 검색 입력, 바꾸기 입력, 결과를 구분하고 영역 간 간격과 설명 줄 간격을 늘렸다. 바꾸기는 펼침 영역으로 제공해 작은 창에서 결과를 더 일찍 볼 수 있다.
- 검색 결과는 파일명·상위 경로·행 위치·본문을 구분한다. 긴 파일명은 여러 줄로, 경로와 본문은 제한된 줄과 전체 내용 도움말로 표시한다.
- 바꾸기 검토는 파일별 카드와 변경 전·후 열로 구분한다. 목록만 스크롤하고 하단 적용·취소 버튼은 유지한다. 적용 결과의 상태와 경로도 분리했다.
- 파일 행은 32pt, 글자는 13pt로 조정했다. 목차 제목은 최대 3줄과 전체 제목 도움말을 제공한다.
- 체크리스트는 Space·Enter로 변경하고 포커스를 유지한다. 복잡한 목록의 HTML 서식 공백을 건너뛰며, 실제 구문 위치를 각 항목에 연결해 코드 예제와 이스케이프된 문자 표기를 편집 대상에서 제외한다.
- 원문 자체의 띄어쓰기는 자동으로 고치지 않는다. 연속 공백 및 강조 전후 공백의 표시와 원문 보존을 검증했다.

## 실제 화면 확인

macOS 26.6.2, Apple Silicon arm64, Debug 앱과 실제 WKWebView에서 확인했다. 검증용 앱 식별자와 자체 생성 QA 문서를 사용했다.

- 작은 창(약 812×560)과 넓힌 창에서 검색 패널, 스크롤 접근, 파일·목차 화면을 확인했다.
- 긴 한글 파일명, 여러 단계의 폴더 경로, 긴 검색 문장과 목차 제목을 확인했다.
- 바꾸기 펼침, 파일별 미리보기, 긴 경로의 줄바꿈, 고정된 하단 버튼을 확인했다.
- 자체 생성 QA 문서 3개에 적용하고 저장 완료 결과가 이전 미리보기와 섞이지 않는 것을 확인했다.
- 본문의 연속 공백, 강조 양옆 공백, 코드 블록을 포함한 체크리스트 표시를 확인했다.
- 최종 앱에서 이스케이프된 문자 표기와 코드 예제는 문자로 남고 실제 항목만 체크박스로 표시됐다. 두 번째 항목을 클릭하고 Space로 되돌린 뒤 포커스 유지와 저장된 원문의 완전 일치를 확인했다.

- 변경분 공백 오류 검사 통과.

## 남은 범위

- 물리 두벌식 키보드 조합 검증은 미완료다. 프로그램 입력과 키 이벤트 테스트를 실제 한글 IME 검증으로 간주하지 않는다.
- Intel Mac, macOS 14, 실제 클라우드 동기화 폴더, 다른 Mac 배포·서명·공증은 이번 검증에 포함하지 않았다.
- 설치된 Applications 앱 및 배포 ZIP은 이번 보완으로 교체하지 않았다.
- 화면을 직접 검토한 범위는 위 사용 흐름이며, 모든 문서·설정 조합의 완전한 UI 검증을 의미하지 않는다.
