# Windows UI 재설계 — 2026-09-10

## 기준과 조사

사용자가 기존 Electron UI가 실행하고 싶지 않을 정도로 조잡하다고 평가했고, Typora Windows를 조사하여 재설계하도록 요청했다.

- [Typora 파일 관리](https://support.typora.io/File-Management/): 문서 중심 화면, 파일/목차 사이드바, Windows 하단 사이드바 전환, 폴더 메뉴와 항목별 컨텍스트 작업.
- [Typora Windows](https://support.typora.io/Typora-on-Windows/): Windows 환경의 메뉴와 테마 동작.
- [Typora 단축키](https://support.typora.io/Shortcut-Keys/): Ctrl+Shift+L 사이드바, Ctrl+/ 원문 전환.

참조의 정보 구조와 화면 절제를 적용했다. Typora의 브랜드/코드를 복제하거나 미구현 기능을 구현됐다고 표시하지 않는다.

## 변경

- 큰 상단 작업 버튼을 파일/편집/서식/보기 메뉴로 전환. 문서 이름은 낮은 대비로 표시.
- 250px 기본 사이드바, 얇은 경계, 파일/목차/찾기 전환, 파일 아이콘과 차분한 선택 행.
- 파일 도구 격자를 폴더 옆 메뉴로 이동. 오른쪽 클릭으로 선택 항목 작업에 접근. 문서는 한 번 클릭으로 열기.
- 하단 사이드바 숨기기·설정·원문 전환. 저장 상태와 문서 통계는 작은 글자로 표시.
- 라이트·다크·나이트 주변 UI와 편집기의 배경·텍스트 색조 통일. 정상 저장의 초록색 강조 제거.
- 결과 알림은 문서를 밀어내지 않는 작은 하단 안내. 오류는 구분되는 경계색 유지.
- 검색/바꾸기 입력 폭, 설정 값 표시, 모달 간격, 메뉴 키보드 조작과 Escape.
- 좁은 편집 화면에서 제목 기호가 잘리지 않는 여백과 한국어 단어 단위 줄바꿈.

Mac 앱·공유 편집 알고리즘·저장/복구/검색 데이터 처리에는 변경 없음. Windows 전용 스타일만 추가. 기존 미완료 기능인 표 전용 편집, 내보내기, 집중/타자기 모드는 이번 UI 작업 범위에 포함하지 않음.

## 검증

macOS arm64에서 Electron 44.3.0 실제 창 실행:

- Windows 코어 13개, 통합 17개, 파일/검색 UI 9개 검증 통과.
- 새 디자인 흐름 8개: 한 번 클릭 열기, 세 테마 일치, 사이드바 숨김/목차 복원, 메뉴 방향키/Escape, 파일 컨텍스트 메뉴, 최소 창 검색 입력·폴더 메뉴 영역, 렌더러 예외 없음.
- 기본 창 및 800×560 내용 영역 화면 직접 검토. `Windows/test-results/design-*.png`.
- 1,200개 파일: 5.2초 유휴 읽기/재검색 0회, 20회 입력 중 트리 DOM 변경/전체 트리 전송 0회. 원문 저장 확인. `build/ui-design-performance.json`.
- 최종 ZIP의 모든 UI/편집 리소스와 소스 일치, ZIP 무결성, AMD64 PE와 실행 런타임 포함 여부는 패키지 검증기로 통과했다. 최종 app.asar를 직접 실행한 디자인 8개·통합 17개 검증도 다시 통과했다.

실제 Windows PC의 창 프레임/글꼴/IME는 미검증. Mac에서 실행한 동일 Electron 코드의 UI 증거이며 Windows 실기 증거로 일반화하지 않는다. 배포본은 기존과 같이 개인용 미서명 ZIP이며 전체 압축 해제 후 EXE 실행 방식이다.
