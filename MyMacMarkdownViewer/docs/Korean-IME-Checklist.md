# 실제 두벌식 키보드 검증

준비일: 2026-09-09. 상태: **미실행 — 실제 키보드 결과 대기**.

2026-09-09 사용자 결정: 이번 작업은 앱 교체까지만 진행하며 실제 IME 검증은 미완료로 유지한다. 추후 검증 환경은 Mac 내장 키보드와 macOS 두벌식이다. 환경 선택은 테스트 통과를 의미하지 않는다.

이 절차는 브라우저의 조합 상태 시뮬레이션과 별개다. 텍스트 붙여넣기나 자동 키 전송으로 통과 판정하지 않는다.

## 준비

1. 검증할 앱의 버전과 실행 경로, macOS 버전, 키보드와 입력 소스를 적는다.
2. 앱에서 새 문서를 만들고 테스트용 폴더에 `한글-입력-검증.md`로 저장한다. 실제 작업 문서는 사용하지 않는다.
3. 아래 내용을 새 문서에 붙여넣어 시작 상태를 만든다. 검증 과정의 한글은 실제 키보드로 입력한다.

```markdown
# 제목 입력 위치

앞 문장 교체대상 뒤 문장 👩🏽‍💻

- 첫 번째 항목
- 두 번째 항목

> 인용문 입력 위치

| 항목 | 내용 |
| --- | --- |
| 한글 | 수정 위치 |
```

## 확인 항목

각 항목은 라이브 편집과 원문 모드에서 각각 확인한다. 조합 중에는 글자 아래의 조합 표시가 남아 있는 상태를 사용한다.

| 항목 | 실제 키보드 조작 | 통과 기준 | 결과 |
| --- | --- | --- | --- |
| 기본 조합 | 본문 끝에 `한글 입력 확인`을 직접 입력 | 자모 분리, 중복, 누락 없음 | 미확인 |
| 조합 중 삭제 | `한`을 입력한 직후 Backspace로 조합을 지우고 `글` 입력 | 지워진 조합이 다시 나타나지 않고 주변 문장 유지 | 미확인 |
| 선택 교체 | `교체대상`만 선택하고 `새로운 내용` 입력 | 선택 부분만 교체되고 뒤 문장과 이모지 유지 | 미확인 |
| 블록 이동 | 제목에서 한글 조합 중 목록으로 클릭 이동 후 계속 입력 | 이전 조합이 정상 확정되고 새 위치에만 입력 | 미확인 |
| 목록·인용문 | 목록과 인용문에서 한글 입력 후 Enter·Backspace 사용 | 내용·들여쓰기·커서 위치가 예상대로 유지 | 미확인 |
| 표 원문 | 표를 클릭해 원문을 열고 셀 내용에 한글 입력 | 표 문법과 다른 셀 유지 | 미확인 |
| 조합 중 실행 취소 | 한글 조합 중 ⌘Z 사용 후 다시 입력 | 조합 잔상·중복·주변 내용 손실 없이 계속 입력 가능 | 미확인 |
| 확정 후 실행 취소 | 한글 문장을 입력하고 방향키로 확정 후 ⌘Z·⌘⇧Z 사용 | 입력 내용이 취소·복원되고 이모지 유지 | 미확인 |
| 모드 전환 | 조합 중과 확정 후 각각 ⌘⇧M 사용 | 입력 내용 손실·중복 없이 전환하거나 조합 종료까지 안전하게 보류 | 미확인 |
| 저장·다시 열기 | 조합 확정 후 2초 대기, ⌘S, 다른 문서를 연 뒤 다시 열기 | 마지막 입력과 표·이모지가 그대로 유지 | 미확인 |

실행 취소의 조합 단위가 애매하면 같은 입력을 macOS 기본 텍스트 편집기에 수행해 비교한다. 단위 차이만으로 데이터 손실이라고 판단하지 않되, 앱에만 발생하는 누락·중복·커서 오류는 실패로 기록한다.

모든 항목의 실제 결과를 확인한 뒤에만 실제 IME 검증 완료로 기록한다. 이 절차만으로 Intel·다른 macOS 버전·클라우드 동기화·배포 공증까지 검증한 것으로 간주하지 않는다.
