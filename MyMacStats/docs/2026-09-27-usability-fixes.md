# 2026-09-27 사용성 점검 후 수정 및 검증

## 수정 범위

- 일반 프로세스는 PID별로, 앱은 실제 번들 경로별로 구분한다. 동명 실행 파일과 다른 위치의 동명 앱을 합치지 않는다.
- 앱 전체 종료와 선택한 PID의 개별 종료를 별도 버튼으로 제공한다. 각각 확인창 및 강제 종료 단계와 최신 PID 검증을 유지한다.
- 알림 권한 응답을 기다리는 동안 측정과 종료 직전 검증이 계속 진행된다. RAM이 회복된 뒤 오래된 알림을 발송하지 않는다.
- PID 검색 결과에 일치하는 프로세스를 상세에서 우선 선택한다. 60개 그룹 및 6개 하위 프로세스 제한을 제거한다.
- CPU 경고와 위험 지속 시간을 독립적으로 판단해 부하 상승 중 경고가 정상으로 돌아가지 않는다.
- 메뉴바 CPU 순위는 대시보드의 검색 및 정렬에 영향을 받지 않는다.
- 배터리 충전/방전 시간, 계산 중, 충전 마무리, 완충 및 점검 필요/정보 없음 상태를 구분한다.
- 디스크 제한 스캔은 부분 추정으로 표시한다. 다시 측정 및 Finder에서 확인하는 버튼을 제공한다.
- 검색 결과 없음/초기화/표시 개수, CPU 백분율 기준, 실제 측정 주기를 안내한다. 단순 지표와 설정은 2열 화면으로 표시하고 macOS 색상 설정을 따른다.
- 경로 그룹화 과정에서 파일 시스템 접근을 제거하고 목록 렌더링 중 반복되는 선택 계산을 줄였다.

## 검증 결과

- Swift XCTest 113개 통과: 기존 97개와 회귀 검증 16개.
- 최종 production 구성 빌드, 앱 번들 및 개인용 zip 생성, 코드 서명 검증 통과.
- 실제 macOS 화면에서 PID 6430 검색과 상세 일치, 6개를 넘는 하위 목록, 개별 종료 확인창 및 취소를 확인했다.
- 검색 결과 없음과 초기화, 충전 마무리 표시, 디스크 다시 측정, 실제 항목별 주기가 표시되는 설정 화면을 확인했다.
- 최종 설치본에서 813개 그룹 목록의 끝까지 스크롤하고 처음으로 돌아오는 것을 확인했다.
- 종료 신호의 대상과 종류는 모의 signal sender로 검증했다. 사용 중인 다른 앱에 종료 신호를 보내는 검증은 하지 않았다.
- 배터리 불량/계산 중 및 디스크 스캔 실패는 fixture 검증이며, 물리적 배터리 불량이나 실제 권한 거부를 강제로 만들지는 않았다.
